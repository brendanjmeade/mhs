# website

The project site, published at <https://brendanjmeade.github.io/mhs/>.

Astro, four pages, no framework runtime. Built and deployed by
`.github/workflows/deploy-website.yml` on every push to `main` that touches
`website/`. The workflow passes `SITE` and `BASE`, deriving the base path from
the repository name, so `astro.config.mjs`'s defaults exist only for `npm run
dev`.

```sh
npm install
npm run dev        # http://localhost:4321/mhs/
npm run build && npx astro preview
```

**Check the built site, not only `dev`.** Every asset fetch goes through
`import.meta.env.BASE_URL`; a hardcoded `/data/...` works in `dev` and 404s in
production, and `astro preview` is where that shows up.

The styling is the sibling site's (`brendanjmeade.github.io/mbem`) with one
change: the prose rules for `pre`, `code` and `table` live in `main.css` rather
than in one page's `is:global` block, because a rule that applies to every page
belongs in the stylesheet every page loads — and both prose pages here carry
tables.

## The data

Both figures are generated by hand and committed. Neither is computed in the
browser.

```sh
python website/scripts/make_payload.py fault                   # seconds
python website/scripts/make_payload.py volume --spacing 1.5    # minutes
```

`fault` builds the home page's clickable interaction matrix: 256 triangles,
three 256×256 float32 matrices (shear, normal, Coulomb). It **refuses to write**
if the shear self-interaction diagonal is not negative everywhere, because that
single fact is what fixes the meaning of the colours, and getting it backwards
would invert the caption and still look plausible.

The page currently shows **shear only**, so it fetches `shear.bin` and nothing
else. `normal.bin` and `cfs.bin` still ship — 256 kB each, never requested by a
visitor — so that restoring the Coulomb view is a page edit rather than a
regeneration. Delete them if that stops being worth 512 kB in the repo.

`volume` builds the Examples viewer: a half space and a full space on one grid,
plus their difference, three fields each. Start coarse — `--spacing 4` runs in
under a minute and tells you what the real one will cost. Observer chunks are
contracted against the slip as they are built, because the matrix for the whole
grid could never be allocated.

Two format decisions are load-bearing, both inherited:

- **log10 into uint8, never a float texture.** `OES_texture_float_linear` is at
  roughly 54% on iOS, and a float32 3-D texture with `LinearFilter` there is
  texture-incomplete: it samples as black with no error raised.
- **Index 0 means "no data".** The grid reaches above `z = 0` and the body does
  not fill it, so a reader must be able to tell an absent voxel from a small one.

The quantisation is checked against an *arithmetic* bound rather than a number
borrowed from another dataset: 254 levels across `d` decades put the levels
`d/253` apart, so the worst relative error is `10**(d/506) - 1`. The script
decodes what it wrote, prints measured-versus-bound per array, and exits
non-zero if any array is over. Read that table; no gate covers this encoder.

## Why the encoder is not in the package

The sibling project keeps its exporter in its Python package so a gate can cover
it. `mhs` declares two runtime dependencies and treats the omissions as design,
so a web exporter inside it would be exactly the scope that package refuses.
The round-trip check above is what stands in for the gate.
